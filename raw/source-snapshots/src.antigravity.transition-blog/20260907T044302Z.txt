<img

    src="https://storage.googleapis.com/gweb-developer-goog-blog-assets/images/GeminiCLI-AntigravityCLI_1200x600_BlogHeader.original.png"
    alt="GeminiCLI-AntigravityCLI_1200x600_BlogHeader"
/>  <div class="inner-block-content rich-content">
    <p data-block-key="fr9q1">When we shipped Gemini CLI last year, our goal was to bring the magic of Gemini directly into your terminal. Along the way, we’ve learned a lot from our community of millions of users, with over 100,000 GitHub stars, 6,000 merged pull requests, and hundreds of contributors, including: you love a good terminal UI, you appreciate that we ship weekly releases, and your workflows have simply outgrown those early days of 2025.</p><p data-block-key="1jmnj">Gemini CLI proved the terminal could be an incredible interface for agentic tasks, but your needs shifted. You now require multiple agents communicating with each other to split up the work and solve complex problems. This means your terminal tools need to share a unified backend with the rest of your workflow.</p><p data-block-key="6vn1d">Listening to your feedback made one thing clear: we can serve you best by pouring our energy into a single product built for today&#x27;s multi-agent reality. To deliver the single platform you need to build the future, we&#x27;re unifying our efforts into <a href="http://antigravity.google/blog/introducing-google-antigravity-2-0">Google Antigravity</a>, our premier agent-first development platform, which includes a powerful server-side harness and a brand-new terminal experience: <a href="http://antigravity.google/blog/introducing-google-antigravity-cli">Antigravity CLI</a>.</p><p data-block-key="4o4go">While there won&#x27;t be 1:1 feature parity right out of the gate, we made sure Antigravity CLI keeps the most critical features of Gemini CLI: Agent Skills, Hooks, Subagents, and Extensions (now as Antigravity plugins). Whether you use Gemini CLI to get quick, grounded answers, scaffold and build out a new coding project, or help provision your cloud infrastructure, you can still do all of that right in Antigravity CLI. And to make your experience better, we focused on the things that matter most to you, like:</p><p data-block-key="dl1dd"></p><ul><li data-block-key="1ptro">Faster execution: Built in Go, Antigravity CLI is snappier and more responsive.</li><li data-block-key="6nsac">Asynchronous workflows: Antigravity CLI orchestrates multiple agents for complex tasks in the background, letting you run large-scale refactors or research several topics without locking up your terminal session.</li><li data-block-key="r120">Unified architecture: Antigravity CLI shares the same agent harness as <a href="https://antigravity.google/blog/introducing-google-antigravity-2-0">Antigravity 2.0</a>, the new Antigravity desktop application, ensuring that all future improvements to core agents are automatically applied wherever you use them.</li></ul><p data-block-key="b8574"></p><h3 data-block-key="fmdij" id="important-timeline-for-consumers"><b>Important timeline for Consumers</b></h3><p data-block-key="bn5ok">Starting today, <a href="https://antigravity.google/download">Antigravity CLI</a> is available to everyone.</p><p data-block-key="fbrsu">On June 18, 2026, Gemini CLI and Gemini Code Assist IDE extensions will stop serving requests for Google AI Pro and Ultra, as well as those using it free of charge using <a href="https://developers.google.com/gemini-code-assist/docs/overview#supported-features-gca">Gemini Code Assist for individuals</a>.</p><p data-block-key="fmhjm">We are here to help make the transition to Antigravity CLI and Antigravity 2.0 as smooth as possible. You can get started now with our <a href="http://antigravity.google/docs/gcli-migration">technical documentation</a>, and we will be releasing video walkthroughs in the coming weeks.</p><p data-block-key="ajlum">For <a href="https://developers.google.com/gemini-code-assist/docs/review-repo-code">Gemini Code Assist for GitHub</a>, this change will also apply and on June 18, 2026, there will be no new installations on Github organizations and requests in the following weeks will stop being served.</p><h3 data-block-key="t7chf" id="for-enterprise-customers"><b>For enterprise customers</b></h3><p data-block-key="2ugfd">If your organization uses Gemini CLI or our IDE extensions via a Gemini Code Assist Standard or Enterprise license, or if your organization uses Gemini Code Assist for GitHub through Google Cloud, your access remains unchanged. We’ll continue to support Gemini CLI and Gemini Code Assist with access to the latest Gemini models and other updates. Gemini CLI will remain accessible via paid Gemini and Gemini Enterprise Agent Platform API keys. And if you’re excited to try Antigravity CLI, you can use it now with your <a href="http://antigravity.google/blog/google-antigravity-for-enterprises">Google Cloud projects</a>.</p><p data-block-key="5p76u">We welcome your feedback in the Antigravity CLI <a href="https://github.com/google-antigravity/antigravity-cli">community forum</a>, especially if there is a feature you’d like to request during this transition. We look forward to seeing what you build next with Antigravity 2.0 and Antigravity CLI.</p><p data-block-key="fnuo1"></p><p data-block-key="d454k">Explore this announcement and all Google I/O 2026 updates on <a href="https://io.google/2026/?utm_source=blogpost&amp;utm_medium=pr&amp;utm_campaign=devblogs&amp;utm_content=">io.google</a>.</p>

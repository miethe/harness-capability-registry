How to read this registry

The registry keeps an immutable/source-faithful release ledger separate from a reviewed current capability graph.

  • Unknown means evidence is incomplete; it is not a negative claim.
  • Every capability is evaluated independently for a human, the in-harness model, an external orchestrator, CI, and an administrator.
  • Release-note extraction creates candidates. Current capability claims require official evidence.
  • Click any matrix cell or result card to inspect evidence, invocation surfaces, versions, and limitations.

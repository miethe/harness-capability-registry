# Coverage and Limits

The checked-in seed is intentionally honest about uneven upstream source quality.

- Raw changelog-backed tracks contain broad historical sections and detailed normalized change items.
- GitHub-release-only and package-registry tracks contain curated recent seed releases; a networked `hcr update` backfills the configured 120-day window.
- Current capability claims are documentation-derived and generally stronger than release-history completeness.
- A release count cannot be used as a proxy for feature completeness.
- A missing capability implementation means “not yet modeled,” not “unsupported.”
- `unknown` actor access means evidence is insufficient.
- Product versions are reconciled from the highest known release, but installed versions remain environment-specific and are not yet inventoried.
